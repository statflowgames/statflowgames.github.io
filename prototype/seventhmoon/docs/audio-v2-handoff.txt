일곱 번째 달 — 기합·각성·몬스터·효과음 정리 (Audio V2)
2026-11-20

반영 내용
- 한국어 대사/구호를 제거했다. 주인공은 언어 없는 숨소리·기합·신음·웃음만 사용한다.
- 6명 모두 공격/강공격/피격/쓰러짐/승리/각성을 자기 목소리로 재생한다.
- 하르반은 낮고 든든하게, 미라엘은 선명하고 짧게, 오델리아는 따뜻하고 힘있게,
  키르는 빠르고 가볍게, 세릴은 차분하게, 녹타는 낮고 절제된 톤으로 나눴다.
- 기존 파형/포먼트 기합, 한국어 TTS 후보로 되돌아가는 경로를 막았다.
- 새 기합은 공개 음성 합성기의 비언어 후보를 편집한 음원이다. 배우가 연기한 실녹음은 아니다.
- 같은 기합이 연속해서 나오지 않게 순환하고, 공격보다 피격/각성/쓰러짐을 우선한다.
- 목소리를 겹겹이 쌓지 않고 이전 기합을 짧게 페이드한다. 목소리에 임의 피치 변조를 하지 않는다.

각성
- 전사 음원을 모든 직업에 재생하던 연결을 직업별로 분리했다.
- 컷인/기합은 준비 때, 발동 효과는 실제 Game 이벤트 때 재생한다.
- 전사: 금속 방패 충격과 무거운 밀어내기.
- 미라엘: 운석 낙하 뒤 화염/얼음/번개 충돌을 각각 동기화.
- 오델리아: 신성한 발동음과 작은 파동음. 합성 성가/사람 모음 소리는 제거.
- 키르: 순간 이동과 짧은 연속 참격.
- 세릴: 신호 화살 발사와 작고 얇은 화살비.
- 녹타: 화면이 어두워진 뒤 실제 폭발 순간에 낮은 붕괴음. 합성 괴성은 제거.

몬스터·보스
- AI 대역 리그가 아닌 실제 몬스터 id로 소리 계열을 고른다.
- 그롤린/쥐족/늑대/해골/미라/점액/전갈·뱀/병정·골렘/날개 괴물/거인/흑월·공허/해적·광부/용: 13계열.
- 공격/피격/사망/발견/웃음/도주/주술/포효를 분리했다.
- 해골은 뼈 마찰, 미라는 마른 붕대와 숨, 점액은 기포, 골렘은 재질 충격으로 표현한다.
- 공격 기합을 1.3배 높여 피격음으로 쓰던 연결과 획일적인 사망 효과음을 제거했다.
- 적 소리는 최대 3개, 연속 피격은 간격을 제한한다. 주인공 기합 중 적 소리를 낮춘다.

일반 효과음
- 36개 그룹을 새로 다듬고, 타격/방어/패링/위험 알림처럼 역할이 분명한 기존 24개 그룹은 유지했다.
- 골드: 약0.13초의 짧은 동전 소리 3종. 음계 상승/음높이 계단/잔향을 제거했다.
- 달리기: 짧은 흙 발소리와 천/가죽/건조한 갑옷 마찰로 구분한다. 반복되는 금속 종 울림은 제거했다.
- UI 선택/열기/닫기/지도는 짧은 클릭과 종이 마찰, 장착/상자는 재질 소리로 바꿨다.
- 점프/착지/구르기/넉백/파괴/물약/회복/두루마리를 용도에 맞게 짧게 정리했다.
- 궁수의 발사는 활시위, 마법사의 발사는 화염/얼음/번개로 연결했다.
- 배경음악과 보상 징글은 이번 효과음 수정 범위에서 유지했다.
- 설정의 '기합·괴성' 음량으로 공격 효과음과 별도로 조절할 수 있다.

납품과 검증
- 새 최종 음원 288개: 글로벌 기합72 + 각성12 + 몬스터143 + 일반 효과음61.
- assets/audio/manifest.json은 실제 게임에서 쓰는 새 파일들을 가리킨다. 기존 원본은 보존한다.
- 음량/EQ/시작·끝 여백을 맞추고, AAC로 압축한 뒤 다시 디코딩해 피크를 검사했다.
- node tools/test_audio_v2.cjs: 6직업/13계열 연결, 한국어/포먼트 후보 제외, 반복·중첩 우선순위,
  기합 음량, 동전의 음높이 고정, 달리기의 새 발소리, 파일 누락 검사를 통과했다.
- node tools/test_awaken_audio_routes.cjs: 실제 Hero/Game의 6직업 각성 호출 경로를 통과했다.
- 기존 캐릭터 리그/비율 검사도 통과했다.

검토
- tools/audio-review-v2.html: 직업별 기합/각성/피격/쓰러짐/승리, 동전10개, 달리기, 몬스터 종류별 소리.
- tools/ability-review.html?scene=abilityReview: 실제 각성/스킬 동작과 소리를 함께 확인한다.
