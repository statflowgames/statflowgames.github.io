1. 사용자 최종 결정

주인공: V5 짧은 기합을 사용한다.
- 쓰러짐은 맞고 힘이 풀리는 짧은 "으악" 느낌 (약 0.38~0.54초).
- 승리는 짧고 자신감 있는 Hah. 기합 (약 0.34~0.54초).
- 여섯 직업의 음색을 구분하며 한국어 대사는 사용하지 않는다.
- 긴 V4 원음을 1/3로 줄인 주인공 V7 시험은 사용자가 청취 후 철회했다.
  V7이나 긴 비명/포효로 다시 바꾸지 말 것.

보스: V6 사망음을 사용한다.
- 사용자가 비명의 느낌은 좋다고 했고 길이만 1/3로 줄이도록 요청했다.
- 보스 13명, 대부분 0.843초, 아즈말 0.899초.
- 기존 목소리와 음높이를 유지한 축약본이다.
- 보스 피격음의 큰 음량과 13명 개별 음색은 V3 기준을 유지한다.

음악: 새 편곡 V3가 확정이다.
- BGM 30곡 + 짧은 음악 8개. 현악/피아노/목관 중심의 새 편곡.
- 이전 아케이드풍 bgm_* 원본 대신 manifest.musicFiles의 mv3_*를 재생한다.

2. 실제 적용 파일 — manifest가 기준

assets/audio/manifest.json
- 주인공 bank key: hv2_vo_<직업>_global_ko / ..._victory
- 선택 파일: hv2_vo_<직업>_global_ko_v5.m4a / ..._victory_v5.m4a
- 직업: warrior, mage, paladin, rogue, ranger, hexblade
- 보스 bank key: ev2_boss_<보스ID>_die
- 선택 파일: ev2_boss_<보스ID>_die_v6.m4a
- heroEmotion.revision = 5 / bossDefeat.revision = 6
- audioVersion = v6-330ea8e518d0
- musicVersion = v3-2a32c48c3551

assets/audio에는 비교용 옛 버전도 남아 있다.
파일명의 가장 높은 버전을 임의로 고르거나 디렉터리 전체를 자동 재생하지 말고,
현재 manifest.sfx와 manifest.musicFiles에 연결된 파일만 사용한다.
출시용 파일을 옮길 때는 manifest가 참조하는 음원도 함께 복사한다.

3. 코드 연결 — 현재 소스에 이미 반영된 경로를 보존

js/sfx.js
- heroKO(x, heroKey), heroWin(heroKey): 해당 직업의 global 파일 재생.
- 목소리는 playbackRate=1, 무작위 음높이 변경 없음.
- 배경음은 musicFiles 매핑 + musicVersion으로 스트리밍.
- 효과음은 audioVersion 쿼리를 사용하여 이전 캐시를 피한다.
- 기합/괴성 음량 설정과 효과음/BGM 설정을 유지한다.

js/actors.js / js/game.js
- 보스 bossHit()에서 실제 보스 ID로 hurt를 재생한다.
- 보스 치명타 순간 bossDown(x, boss.id)를 한 번 재생한다.
- deathAudioPlayed를 유지하여 뒤늦은 die()/dissolve에서 중복 재생하지 않는다.
- 일반 괴성/공통 붕괴음을 보스 전용 사망음 위에 다시 겹치지 않는다.

직업별 각성 효과, 평타, 몬스터 피격음, 골드/달리기 효과음은
이미 정리된 선택을 유지한다. 이번 복원은 주인공 쓰러짐/승리 V7만 취소한 것이다.

4. 재빌드 시 주의

tools/prep_audio.py의 전체 제작 순서는 V3 → V4 → V5 → 보스 V6이다.
shorten_boss_defeats_v6.py에서 주인공 V7 자동 적용 호출을 제거했다.
tools/shorten_hero_endings_v7.py와 해당 WAV/m4a는 시험 이력으로만 보존한다.
현재 선택을 다시 만들려면 tools/refine_hero_endings_v5.py를 사용한다.
기존 로컬 원본이 있으므로 새 외주/유료 API/계정 연결은 필요하지 않다.
